# POKEMON_GUI
Este repositorio es creado para hacer la interfaz gráfica del mini proyecto 2

el trabajo lo realizamos los 3 integrantes del grupo 

        Diego Garzon     /  Interfaz
        Santiago Aguirre /  Cartas y evoluciones
        Johan Benitez    /  Cambios necesarios en partida para la GUI

Ahora, en vez de una consola , el juego se puede jugar en una ventana, sin necesidad de digitar nada, solo el nombre y listo!

los cambios que hubieron a la logica fueron las evoluciones, hacen que algunos pokemones basicos puedan evolucionar y ser mas poderosos!
